# Landing Page — Compra de Sucata | BR Metais

Landing page focada em tráfego pago e geração de leads para compra de sucata.

## Estratégia aplicada
- Sem menu de navegação para reduzir dispersão.
- Hero focado na intenção “vender sucata”.
- CTAs repetidos levando ao mesmo modal de qualificação.
- Qualificação por perfil, região, material, volume, coleta e prazo.
- Redirecionamento ao WhatsApp +55 41 3604-0031 com os dados preenchidos.
- Materiais aceitos apresentados visualmente.
- Endereço e mapa no final da página.
- Layout responsivo para desktop e mobile.

## Antes de anunciar
Conectar Google Tag Manager / GA4 / Google Ads / Meta Pixel conforme a mídia utilizada. Recomenda-se medir pelo menos:
1. clique para iniciar cotação;
2. avanço no modal;
3. envio para WhatsApp;
4. venda confirmada em CRM/planilha para medir qualidade real dos leads.
